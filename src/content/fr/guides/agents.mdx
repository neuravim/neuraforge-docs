# Les agents NeuraForge

> NeuraForge coordonne une petite équipe d'agents IA spécialisés pour éviter de traiter une demande comme un simple prompt isolé.

## Ce que font les agents

NeuraForge sépare clairement les responsabilités :

- **Lead** : comprend la demande, choisit le bon niveau de workflow et garde la livraison alignée sur l'objectif.
- **Analyst** : étudie le code et le changement demandé avant l'implémentation.
- **Planner** : transforme l'analyse en plan, stories et critères d'acceptation.
- **Dev** : implémente le changement et prépare les tests.
- **Security Reviewer** : recherche les risques applicatifs et les hypothèses dangereuses.
- **QA** : vérifie le résultat par rapport au comportement attendu et au niveau de qualité requis.
- **DocOps** : prépare la documentation opérationnelle pour les livraisons enterprise.

Le point important n'est pas le nombre d'agents. C'est la séparation des rôles : analyse, planification, code, sécurité, QA et documentation ne sont pas fusionnés dans une réponse générique.

## Comment la collaboration fonctionne

Un workflow NeuraForge avance de la compréhension vers l'implémentation puis la vérification. Chaque étape s'appuie sur la précédente, ce qui garde une traçabilité entre la demande initiale et le changement livré.

Vue publique simplifiée :

1. comprendre la demande et le dépôt ;
2. choisir le mode de livraison adapté ;
3. préparer un plan lorsque la tâche le nécessite ;
4. implémenter le changement ;
5. vérifier sécurité et qualité ;
6. documenter le résultat lorsque la livraison enterprise l'exige.

Les contrats internes, la structure des prompts, les schémas de données et les règles d'orchestration font partie de l'implémentation privée de NeuraForge. Ils ne sont pas nécessaires pour utiliser le produit.

## Activation par mode

| Capacité | Flash | Standard | Enterprise |
|---|---|---|---|
| Implémentation rapide | Oui | Oui | Oui |
| Analyse et planification | Légères | Oui | Oui |
| Revue sécurité et QA | Légère | Oui | Renforcée |
| Validation humaine | Non | Optionnelle | Oui |
| Documentation opérationnelle | Non | Optionnelle | Oui |

## Quel niveau choisir ?

- **Flash** : petits changements à faible risque.
- **Standard** : fonctionnalités, intégrations et refactorings courants.
- **Enterprise** : migrations, sécurité, conformité, readiness production et validation métier.

## Comportement personnalisé

Les équipes peuvent adapter NeuraForge avec des règles, providers et playbooks métier sans modifier le produit. Par exemple, une équipe migration peut spécialiser le workflow WildFly vers Spring Boot tout en gardant le même modèle de livraison contrôlée.
