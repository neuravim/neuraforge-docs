# Skills

> Les skills permettent aux équipes de packager des connaissances réutilisables pour NeuraForge sans modifier le produit.

## Qu'est-ce qu'un skill ?

Un skill est un paquet réutilisable de connaissances d'équipe. Il peut décrire comment traiter un domaine, quels standards appliquer ou quels contrôles effectuer pour un type de travail.

Utilisez un skill lorsqu'une simple règle projet ne suffit pas et que l'équipe veut guider NeuraForge de manière répétable sur plusieurs tâches.

## Quand utiliser des skills

Bons cas d'usage :

- attentes de revue sécurité ;
- conformité ;
- playbooks de migration ;
- standards d'ingénierie métier ;
- exigences documentaires ;
- conventions d'onboarding.

Pour une convention de code isolée, utilisez une règle. Pour un workflow réutilisable complet, utilisez un skill.

## Comment les équipes utilisent les skills

Flux typique :

1. identifier un type de travail récurrent ;
2. écrire le guidage une seule fois ;
3. l'attacher aux projets ou workflows concernés ;
4. l'améliorer au fil des retours d'expérience.

Le format interne du manifest, les événements de hooks, les priorités et les détails d'injection dans les prompts relèvent de l'implémentation privée. Côté public, il suffit de savoir que les skills sont versionnés, réutilisables et pensés pour la gouvernance d'équipe.

## Exemples d'utilisation

| Skill | Objectif |
|---|---|
| Standards API | Harmoniser la conception des endpoints |
| Checklist sécurité | Rendre explicites les attentes appsec |
| Playbook migration | Guider la modernisation legacy |
| Politique documentation | Garantir des docs utiles pour les changements importants |

## Installer et gérer les skills

```bash
neuraforge skills list
neuraforge skills install <skill-name>
neuraforge skills enable <skill-name>
neuraforge skills disable <skill-name>
```

Votre organisation peut fournir un registre interne ou un ensemble validé de skills.
