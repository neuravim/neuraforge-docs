# Claude Code

> Claude Code est un très bon choix par défaut pour analyse, planification, revue et ingénierie générale.

## Quand l'utiliser

Utilisez Claude Code CLI lorsqu'il correspond au modèle d'accès IA, à la politique sécurité et au budget de votre équipe. NeuraForge peut fonctionner avec plusieurs providers, ce qui permet d'adapter le choix à chaque environnement.

## Vue d'installation

1. Installer l'outil provider ou configurer l'endpoint.
2. S'authentifier avec la méthode officielle du provider.
3. Sélectionner le provider dans la configuration NeuraForge.
4. Lancer un petit workflow de test avant les travaux sensibles.

```yaml
provider: claude-code
```

## Guide enterprise

Pour les déploiements enterprise, privilégiez un accès approuvé :

- comptes organisation managés ;
- gateways ou proxies IA internes ;
- modèles locaux pour environnements restreints ;
- règles de traitement des données documentées ;
- suivi budget et usage.

Conservez les credentials, politiques de routing, comportement des adapters et détails spécifiques aux providers dans la documentation privée d'exploitation.

## Dépannage

Si un provider ne fonctionne pas :

- vérifiez l'outil CLI ou l'endpoint indépendamment ;
- confirmez l'authentification ;
- vérifiez réseau et proxy ;
- essayez une demande NeuraForge plus petite ;
- basculez vers un autre provider approuvé si le blocage persiste.

## Frontière public/privé

Ce guide public explique comment choisir et activer le provider. Le comportement interne des adapters, le transport des prompts, la logique de fallback et le routing ne font pas partie de la documentation publique.
