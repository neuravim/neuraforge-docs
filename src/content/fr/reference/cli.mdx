# Référence CLI

> Cette référence publique liste les commandes utiles au quotidien. Les détails internes d'exécution ne sont volontairement pas documentés ici.

## Commandes de workflow

### `neuraforge init`

Initialise NeuraForge dans un dépôt.

```bash
neuraforge init
```

### `neuraforge flash <description>`

Lance un workflow rapide pour les petits changements.

```bash
neuraforge flash "Fix the broken health check"
```

### `neuraforge standard <description>`

Lance le workflow normal pour les fonctionnalités produit.

```bash
neuraforge standard "Add a users API with tests"
```

### `neuraforge enterprise <description>`

Lance le workflow contrôlé pour les travaux sensibles ou critiques production.

```bash
neuraforge enterprise "Migrate authentication to the new provider"
```

Options utiles :

- `--provider <name>` : choisir un provider pour l'exécution ;
- `--profile <name>` : utiliser un profil métier ;
- `--trace` : afficher plus de contexte pour diagnostiquer ;
- `--dry-run` : prévisualiser le workflow sans appliquer de changement.

## Commandes de suivi

```bash
neuraforge status
neuraforge status <feature-slug>
neuraforge resume <feature-slug>
neuraforge abort <feature-slug>
```

Utilisez ces commandes pour inspecter ou reprendre un travail créé par NeuraForge.

## Commandes de configuration

```bash
neuraforge config show
neuraforge config get provider
neuraforge config set mode standard
```

## Règles, templates et skills

```bash
neuraforge rules list
neuraforge rules add coding-standards.md
neuraforge template customize spec
neuraforge skills list
neuraforge skills install <skill-name>
```

## Commandes providers

```bash
neuraforge providers list
neuraforge providers doctor
```

Consultez les guides providers pour l'installation et l'authentification.

## Frontière public/privé

La CLI expose une expérience utilisateur simple. L'implémentation interne de l'orchestration, des prompts, du routing provider, des quality gates et des contrats d'artefacts ne fait pas partie de cette référence publique.
