# Glossaire

Agent, Retex, Quality gate... NeuraForge a son vocabulaire. Ce glossaire public explique les concepts côté utilisateur sans exposer les contrats internes d'implémentation.

---

## A

**ADR** — Architecture Decision Record. Document qui trace une décision architecturale significative.

**Agent** — Rôle IA spécialisé dans une partie du flux de livraison : analyse, planification, implémentation, sécurité, QA ou documentation.

**Artefact** — Produit de travail généré pendant un workflow NeuraForge : brief, spec, review ou note opérationnelle.

## B

**Brief** — Synthèse de discovery qui capture la demande, le contexte, les risques et les contraintes.

## C

**Circuit breaker** — Mécanisme de sécurité qui arrête les échecs répétés et demande une intervention humaine.

**NeuraForge** — Framework d'ingénierie assistée par IA qui orchestre des agents spécialisés depuis la CLI.

## E

**Enterprise** — Mode le plus contrôlé, destiné aux travaux sensibles, à la readiness production, à la documentation et à la validation humaine.

## F

**Feature** — Unité de travail traitée par NeuraForge.

**Flash** — Mode rapide pour les petits changements à faible risque.

## L

**Lead** — Rôle de coordination qui garde le workflow aligné avec la demande.

## M

**Mode** — Niveau de workflow : `flash`, `standard` ou `enterprise`.

## P

**Provider** — Backend ou outil IA utilisé par NeuraForge : Claude Code, Gemini, OpenCode, Copilot, Codex ou API custom.

## Q

**Quality gate** — Point de vérification utilisé pour éviter de considérer un travail incomplet comme terminé.

## R

**Retex** — Retour d'expérience utilisé pour améliorer les travaux futurs.

**Routage** — Sélection de provider selon la configuration et la disponibilité.

## S

**Sanitizer** — Couche de sécurité destinée à réduire l'exposition accidentelle de données sensibles.

**Skill** — Paquet réutilisable de guidage d'équipe pour un domaine, workflow ou standard.

**Spec** — Spécification légère qui décrit le comportement attendu et les critères d'acceptation.

**Standard** — Mode par défaut pour les fonctionnalités courantes.

**Story** — Élément de travail avec comportement attendu et critères d'acceptation.

## T

**Token budget** — Garde-fou de coût et d'usage pour les workflows IA.
