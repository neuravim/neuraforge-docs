# Claude Code

> Claude Code is a strong default for analysis, planning, review and general engineering work.

## When to use it

Use Claude Code CLI when it matches your team's preferred AI access model, security policy and budget. NeuraForge can work with multiple providers, so teams can choose the provider that best fits each environment.

## Setup overview

1. Install the provider tool or configure the provider endpoint.
2. Authenticate using the provider's official method.
3. Select the provider in NeuraForge configuration.
4. Run a small test workflow before using it on sensitive work.

```yaml
provider: claude-code
```

## Enterprise guidance

For enterprise deployments, prefer an approved access path:

- managed organization accounts;
- internal AI gateways or proxies;
- local models for restricted environments;
- documented data-handling rules;
- budget and usage monitoring.

Keep credentials, routing policies, adapter behavior and provider-specific internals in private operations documentation.

## Troubleshooting

If a provider does not work:

- verify the provider CLI or endpoint independently;
- confirm authentication;
- check network and proxy settings;
- try a smaller NeuraForge request;
- switch to another approved provider if the issue blocks delivery.

## Public/private boundary

This public guide explains how to choose and enable the provider. Internal adapter behavior, prompt transport, fallback logic and routing implementation are not part of the public documentation.
